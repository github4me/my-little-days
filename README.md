# 小日子 · My Little Days

[English](README.en.md) | 简体中文

代码仓库：[github4me/my-little-days](https://github.com/github4me/my-little-days)。仓库更名不影响现有应用身份、Expo 项目或本机记录。

婴儿成长记录应用（Expo / React Native / TypeScript）。Windows PC 开发，iPhone 真机使用。本机记录无需账号或后端；可选家庭共享使用 .NET API、Azure SQL 与 Entra External ID，需先配置服务。仅在选择宝宝头像时请求相册访问。

## 已实现

- iPhone 安装后的名称按系统语言偏好显示：中文为「小日子」，英文默认名称为「My Little Days」，未匹配语言回退英文。此原生配置需安装新构建生效，不能仅通过在线 JavaScript 更新改变。

- 宝宝姓名、出生日期、性别、可选头像；离线模式保存在本机，家庭共享模式与家庭共享。点击首页头像直接打开档案设置。
- 奶瓶/亲喂记录，实际奶量快捷输入；设置出生日期后，配方奶快捷选项按喂养当天的年龄调整，不覆盖已输入奶量；瓶喂母乳及未知年龄保留原选项。这些仅供便捷记录，并非喂养目标（[来源与年龄分组](docs/FEED-AMOUNT-PRESETS.md)）。不填结束时间可开始计时。首页点击停止后弹出确认窗口，瓶喂显示原选奶量，可用滚轮按 5 mL 步进调整实际奶量，确认后保存；亲喂仅确认时长。结束时间固定为点击停止的时刻，取消则继续喂养。补录添加结束时间时默认开始时间后 20 分钟，可自行修改。支持尿、便、混合尿布记录。
- 一键入睡/醒来、补录与修改，重启后按时间戳恢复计时。
- 体重、身长、头围及 WHO 官方男/女 0–24 月百分位参考线（本地内置）；“全部”可用不同颜色同时查看三项趋势。
- 喂奶、尿布、睡眠分类；可查看近 7 天、2 周、1 个月、3 个月、6 个月或全部的图表和历史。较长范围会合并图表日期以保持清晰。仅当天明细默认展开，较早日期折叠，超过前七个记录日期的历史可继续展开。每日长列表及成长历史先显示五条；删除需确认，不提供撤销。
- 按天汇总奶量、睡眠和尿布；喂奶支持奶量/时长切换，显示距上次间隔；跨日睡眠拆分并对重叠区间去重。
- 「记录」默认显示原有柱状图，标题栏右侧双图标切换日历/柱状图，不再单独占行。日历的「日、周、今天」在下方同一行左侧；按日或周在同一时间轴查看喂奶、尿布和睡眠，支持日期跳转、分类筛选及点击记录查看、编辑或确认删除。重叠记录并列保留，跨午夜时段分日显示。「我的」可即时保存默认视图，保留已有手动偏好，记录页内切换不改变该偏好。
- 「我的」页面设有独立可展开的「致谢」，与「隐私与支持」同级，感谢 Trista（来自 FPH）和她群里的 Mia、Violet、Bill 提出的建议与想法，以及群里妈妈爸爸的支持，期待更多妈妈爸爸加入。
- 每页底部显示应用版本和更新修订号，方便核对当前代码版本；在线更新修订号不代表原生安装包构建号。
- 日历筛选与「日、周、今天」同排，使用全部、喂奶、尿布、睡眠图标；小屏或文字放大导致空间不足时，折叠为一个筛选按钮，打开后显示带文字的选项。
- 本地一次性延时提醒、随最新喂养开始时间自动重置的提醒、每日固定时间提醒、静音和取消。
- 「照护」包含「早教活动」「日常照护」「设置早教」。日常照护可记录体温、洗澡、清洁、口腔和指甲护理，支持时间、备注、历史编辑与删除，较早历史可展开。体温支持小数，默认腋下；预填的 36.8°C 不是测量结果，请按实际读数修改。
- 早教提供家长带领的活动步骤、安全说明、来源链接及自愿每日打卡。月龄分为 0–1、1–2、2–3 月，之后每两个月一组，覆盖未满 25 个月。设置有效生日后默认选中适龄活动，未设置则不选；保留手动选择，跨实际月龄选择时提示但不禁止。
- 语言支持中文、英文及跟随系统；主题支持跟随系统、浅色和深色，用户选择即时保存。「我的」各设置区域可独立展开，包含隐私说明和支持联系方式。
- JSON 导出/导入，严格验证，替换前保留恢复副本。

## 家庭共享 · 完整记录接入，真机与运行验收待完成

在「我的 → 我的账户」登录后，点击宝宝档案下方的「家庭共享」直接进入家庭管理。离线模式仍无需注册；登录后可创建家庭或接受邀请，家庭记录直接显示在首页、记录（日历/柱状图）、成长和日常照护中。

- 管理员首次创建家庭前核对宝宝资料、所有喂养、尿布、睡眠、成长、旧里程碑和日常照护记录，以及当前宝宝头像、提醒规则和设置、早教选择与全部打卡，再确认上传。服务器原子保存这些资料与邀请；家庭资料核对并持久保存到设备后，成功激活也会清理原个人资料及恢复副本，不保留可恢复的个人副本。进行中的计时须先结束。
- 管理员输入家人邮箱，不发送邀请邮件或推送。接收者自行安装后，可选择注册/登录，以核验过的邮箱查看并接受或拒绝邀请。每个账户最多一个家庭；管理员之外最多五人，现有成员与未过期的待接受邀请共同占用名额，取消、拒绝、过期或离开后释放名额。
- 加入下载管理员的家庭资料，**不会上传或合并加入者原有记录**。只有在服务器提交、完整快照核对并持久保存到设备后，才清理并替换旧本机记录、恢复副本、头像、提醒、早教选择及打卡，不保留可恢复的个人副本。未确认或下载、保存失败时保留原资料并暂停切换；清理失败时保留操作意图，按同一操作恢复。
- 新增、编辑、停止计时与删除使用明确保存的操作队列；同一记录版本以服务端首次成功提交为准，冲突提示并刷新，独立及重叠记录保留。成员只能编辑/删除自己的记录，管理员可操作所有记录、资料、邀请和成员。
- 离开或被移除立即失去服务端访问权限，贡献仍留在家庭；设备在检测到撤权后清除家庭缓存与未提交内容。管理员可不提前通知移除成员。家庭共享时关闭本机导入/导出，旧家庭资料不能带入另一个家庭。
- 所有权在被提名成员明确接受后原子交接。管理员删除账户前须完成交接，或移除成员并关闭家庭。普通退出保留贡献；账户删除另行清理关联资料及目录身份，安全回执显示真实进度。
- 当前宝宝头像、提醒规则和设置、早教选择与打卡均参与共享；不会上传设备相册。头像、早教选择和已保存提醒表单设置由管理员管理。语言、主题、视图偏好及手机通知权限不共享；每台手机单独启用、安排和投递通知，下载规则不会自动启用通知。详见[共享资料说明](docs/FAMILY-EXTRAS.md)。独立的开发用界面样例不会绕过真实认证。

部署见 [完整 Azure 设置指南](docs/AZURE-FAMILY-SETUP.md) 和 [服务端说明](server/README.md)。Bicep 复用现有 Linux B1，建立单独 Web App、托管身份及免费额度 SQL，不要求 Key Vault。免费额度耗尽会暂停，无付费回退；清理任务默认每 120 分钟重试，需实测容量和费用。

[GitHub 基础设施工作流](docs/AZURE-GITHUB-INFRA.md) 自动检查相关推送/PR；可信分支的只读 Azure 预览通过后，仍须环境审批才能部署。API 代码使用单独手动发布。保留含 `pilot` 的旧资源名、角色和环境名以兼容现有部署，不代表功能仍限于试点。

现有 Azure 数据库/API 与 iOS preview 的共享资料发布已记录在[发布证据](docs/AZURE-MANUAL-SETUP-RUNBOOK.md#shared-extras-release-evidence-16-september-2026)。发布成功不等于真机验收；两部 iPhone 的照片显示、SQLite 激活与恢复、通知和共享流程，以及真实删除、备份保留与恢复演练仍须记录结果。

## Windows 上启动

1. 安装 Node.js LTS（建议 Node 24 LTS）、Git、VS Code。
2. 在 PowerShell 中克隆仓库并进入项目目录（如果已下载源码，直接在包含 `package.json` 的文件夹打开 PowerShell）：

```powershell
git clone https://github.com/github4me/my-little-days.git
cd my-little-days
npm ci
npm start
```

3. 预览原有本机功能时，可使用与项目 SDK 57 兼容的 Expo Go。电脑和手机连接同一个 Wi-Fi，在手机相机扫描终端二维码。首次安装依赖和加载开发包需要联网；家庭共享登录必须使用新的签名原生构建，不能用 Expo Go 验收。
4. 第一次打开：进入「我的」，填写宝宝名字、出生日期（YYYY-MM-DD）和性别。
5. 如 Windows 防火墙提示，请仅允许开发网络所需的专用网络访问。局域网无法连接时，可在可信网络使用 Expo 的 tunnel 模式；这会通过中转传送开发包。离线模式不上传照护记录；明确创建家庭会上传核对后的完整历史，共享模式的明确保存会发送到家庭服务。

如果 App Store 的 Expo Go 版本不兼容 SDK 57，不要随意升级/降级单个包。使用下面的 EAS 内部分发构建，或整体对齐 Expo SDK 与 Expo Go。

### 先在 PC 查看界面

```powershell
npm run web
```

## 使用说明

- 首页「睡了」立即保存入睡时间；「醒了」结束当前睡眠。补录用卡片下方入口。
- 喂奶快捷数量只是输入选项，不是喂养建议。亲喂时长不转换成毫升。
- 「记录」可切换日历与柱状图。日历按日或周浏览全部或单类记录；柱状图按所选范围汇总并倒序展示历史。新增记录从首页进入。
- 「成长」保留实测曲线和测量记录；测量从此页添加。标准曲线只覆盖 0–24 月，不向外推算。里程碑入口已移除，旧备份中的里程碑数据仍保留，不自动删除。
- 提醒在「我的」设置。喂养可选「随最新喂养」：每次保存、编辑、删除或恢复记录后，应用以开始时间最新的一次喂养加上设定间隔重新安排提醒；也可选仅提醒一次或每天固定时间。上次成功添加的提醒设定会在下次进入时恢复。免打扰/专注模式和系统通知权限可能影响呈现。没有自动作息建议。
- 「导出备份文件」后在 iPhone 分享菜单选择「存储到文件」，自行选择位置。应用不会自动上传备份；选择 iCloud 等位置时，由用户选择的系统服务处理。
- 导入前会预览姓名与记录数量，确认后整体替换，不合并。恢复不改变当前已安排的提醒。
- 备份为未加密 JSON，包含原有本机宝宝档案、喂养/睡眠/尿布/成长等记录及日常照护记录，不含本机头像、语言与主题偏好、提醒设定、系统通知计划、早教选择与打卡或家庭共享数据与凭据；共享模式关闭备份。换机、卸载前保存本机备份。

## 时间与数据边界

事件用带时区的 ISO 时间保存。显示、日期筛选和每日汇总使用当前设备时区（墨尔本设备会采用当地夏令时），旅行改变设备时区会重新分配日统计。生日是无时区的日历日期。手动编辑精度为分钟，首页即时计时保存到毫秒。

睡眠按实际时间差计算，统计合并重叠睡眠区间；进行中睡眠只统计至当前时刻。没有记录的天不等同于实际没有进食或睡眠。

WHO 参考来源、原始表格校验和与绘图口径详见 `docs/WHO-SOURCES.md`。曲线只用于趋势展示，不做诊断、精确百分位计算或早产矫正月龄判断。

离线记录保存在应用沙盒 SQLite。仅登录不上传历史；明确创建家庭会迁移核对后的完整记录，接受他人邀请则下载对方资料并清理原本机资料。共享缓存和已保存队列有独立账户/家庭/授权/历史边界，不会写入个人离线数据库或供备份导出。

应用通过 Expo 更新服务检查和下载软件更新，可能交换技术元数据，但更新请求不包含宝宝记录或照片。系统级设备备份遵循手机系统设置，不等于应用自动同步记录。早教内容供家长参考，不是宝宝的屏幕课程或发育评估。

## 验证

```powershell
npm run verify
npm run export:ios
npm run export:web
```

- `verify`：TypeScript、数据/统计/WHO 与家庭共享单元测试、真实家庭控制器的确定性测试桩（`test:family-controller`）及中英文界面权限/确认流程（`test:family-ui`）。测试模拟身份、HTTP、SQLite 和原生控件边界，不代替 iPhone 验收。
- `export:ios`：生成 iOS JavaScript/Hermes 资源包；不是 IPA 编译、签名或真机验证。
- 浏览器回归和后端测试见 [验证说明](docs/VALIDATION.md)。`.NET 10` 后端运行 `dotnet test server/LittleDays.FamilyApi.Tests`；只有设置指向可丢弃 SQL Server `master` 的 `FAMILY_TEST_SQL_CONNECTION` 才执行真实 SQL 测试，不能指向试点或生产数据库。详见 [服务端说明](server/README.md)。

## 项目结构

- `App.tsx`：简洁首页、成长和页面切换。
- `src/Records.tsx`：三个分类、趋势图、每日汇总和明细。
- `src/EntryEditor.tsx`：五类记录表单与原生时间选择器。
- `src/Settings.tsx`：档案、通知、备份恢复。
- `src/PlayLearning.tsx`、`src/learning.ts`：早教活动、月龄选择与打卡。
- `src/DailyCare.tsx`、`src/care.ts`：日常照护历史与体温输入验证。
- `src/recordRange.ts`：记录时间范围与图表分组。
- `src/PrivacySupport.tsx`：隐私说明与支持信息。
- `src/domain.ts`：版本化数据模型、校验与统计。
- `src/storage.ts`：SQLite 事务保存与恢复副本；`.web.ts` 是开发预览实现。
- `src/backup.ts`：手机文件选择与导出。
- `src/reminders.ts`：设备本地通知，不获取推送 token。
- `src/growth.ts`、`assets/who/`：本地 WHO 参考数据。
- `src/family/`：家庭管理与主界面数据接入、身份认证、网络契约、缓存、草稿和持久队列。
- `server/LittleDays.FamilyApi/`、`server/LittleDays.FamilyApi.Tests/`：.NET 10 API、EF SQL 迁移与后端测试。
- `infra/`、`.github/workflows/`：设置模板、SQL 权限脚本、CI；基础设施改动自动检查及预览后等待审批，API 代码仍单独手动部署。
