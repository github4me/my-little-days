# 小日子 · My Little Days

[English](README.en.md) | 简体中文

代码仓库：[github4me/my-little-days](https://github.com/github4me/my-little-days)。仓库更名不影响现有应用身份、Expo 项目或本机记录。

婴儿成长记录应用（Expo / React Native / TypeScript）。Windows PC 开发，iPhone 真机使用。原有本机记录无需账号或后端；仓库另含独立、受控的家庭邀请试点，使用前需配置服务和获准账户。仅在选择宝宝头像时请求相册访问。

## 已实现

- iPhone 安装后的名称按系统语言偏好显示：中文为「小日子」，英文默认名称为「My Little Days」，未匹配语言回退英文。此原生配置需安装新构建生效，不能仅通过在线 JavaScript 更新改变。

- 宝宝姓名、出生日期、性别、可选本机头像；点击首页头像直接打开档案设置。
- 奶瓶/亲喂记录，实际奶量快捷输入；设置出生日期后，配方奶快捷选项按喂养当天的年龄调整，不覆盖已输入奶量；瓶喂母乳及未知年龄保留原选项。这些仅供便捷记录，并非喂养目标（[来源与年龄分组](docs/FEED-AMOUNT-PRESETS.md)）。不填结束时间可开始计时。首页点击停止后弹出确认窗口，瓶喂显示原选奶量，可用滚轮按 5 mL 步进调整实际奶量，确认后保存；亲喂仅确认时长。结束时间固定为点击停止的时刻，取消则继续喂养。补录添加结束时间时默认开始时间后 20 分钟，可自行修改。支持尿、便、混合尿布记录。
- 一键入睡/醒来、补录与修改，重启后按时间戳恢复计时。
- 体重、身长、头围及 WHO 官方男/女 0–24 月百分位参考线（本地内置）；“全部”可用不同颜色同时查看三项趋势。
- 喂奶、尿布、睡眠分类；可查看近 7 天、2 周、1 个月、3 个月、6 个月或全部的图表和历史。较长范围会合并图表日期以保持清晰。仅当天明细默认展开，较早日期折叠，超过前七个记录日期的历史可继续展开。每日长列表及成长历史先显示五条；删除需确认，不提供撤销。
- 按天汇总奶量、睡眠和尿布；喂奶支持奶量/时长切换，显示距上次间隔；跨日睡眠拆分并对重叠区间去重。
- 「记录」默认显示原有柱状图，标题栏右侧双图标切换日历/柱状图，不再单独占行。日历的「日、周、今天」在下方同一行左侧；按日或周在同一时间轴查看喂奶、尿布和睡眠，支持日期跳转、分类筛选及点击记录查看、编辑或确认删除。重叠记录并列保留，跨午夜时段分日显示。「我的」可即时保存默认视图，保留已有手动偏好，记录页内切换不改变该偏好。
- 「我的」页面设有独立可展开的「致谢」，与「隐私与支持」同级，感谢 Trista（来自 FPH）和她群里的 Mia、Violet、Bill 提出的建议与想法，以及群里妈妈爸爸的支持，期待更多妈妈爸爸加入。
- 每页底部显示应用版本和更新修订号，方便核对当前代码版本；在线更新修订号不代表原生安装包构建号。
- 日历筛选与「日、周、今天」同排，使用全部、喂奶、尿布、睡眠图标；小屏或文字放大导致空间不足时，折叠为一个筛选按钮，打开后显示带文字的选项。
- 本地一次性延时提醒、随最新喂养开始时间自动重置的提醒、每日固定时间提醒、静音和取消。
- 「照护」包含「早教活动」「日常照护」「设置早教」。日常照护可记录体温、洗澡、清洁、口腔和指甲护理，支持时间、备注、历史编辑与删除，较早历史可展开。体温支持小数，默认腋下；预填的 36.8°C 不是测量结果，请按实际读数修改。
- 早教提供家长带领的活动步骤、安全说明、来源链接及自愿每日打卡。月龄分为 0–1、1–2、2–3 月，之后每两个月一组，覆盖未满 25 个月。设置有效生日后默认选中适龄活动，未设置则不选；保留手动选择，跨实际月龄选择时提示但不禁止。
- 语言支持中文、英文及跟随系统；主题支持跟随系统、浅色和深色，用户选择即时保存。「我的」各设置区域可独立展开，包含隐私说明和支持联系方式。
- JSON 导出/导入，严格验证，替换前保留恢复副本。

## 家庭邀请试点 · 源码已实现，尚未部署

入口在「我的 → 家庭邀请试点」。这是供两个经核对账户验证的独立测试空间，只使用虚构的宝宝昵称和**已结束的瓶喂记录**；不是完整家庭同步或公开测试版。现有宝宝档案、喂养、睡眠、尿布、成长、日常照护、计时器、早教、设置、照片和备份不会迁移或上传。

- 手机通过 Entra External ID 邮箱验证码登录。管理员可预先保存尚未注册的邮箱邀请，不发通知；核验后的接收者登录查看并接受或拒绝，邀请 30 天到期。每个账户最多一个家庭，公开注册仍需后续身份核验接入。
- 成员可新增瓶喂记录，只能编辑/删除自己的记录；管理员可修改任何记录，并独享邀请、成员管理和试点宝宝资料编辑权限。输入先保存为私人草稿，明确保存后才加入持久队列。
- 同一记录版本以服务端首次成功提交为准，独立及重叠记录保留。同账户、家庭、授权和历史内可检查冲突；退出、移除或切换环境清除旧缓存及所有草稿/队列，不能跨家庭复制。
- 管理员提名现有成员，待对方接受后原子交接权限。关闭家庭前须移除其他成员；删除管理员账户前须先关闭家庭或完成交接。普通退出保留贡献，账户删除另走数据库及身份清理流程；设备可凭安全回执查询进度。真实账户删除仍需 Azure/Graph、配置与备份清理验收。
- 退出登录前会提示尚未发送的内容；确认后清除此设备的试点缓存、草稿、队列和登录信息，原有本机记录不受影响。试点数据暂不支持导出、导入或历史迁移。

先按 [Azure 试点设置指南](docs/AZURE-FAMILY-PILOT-SETUP.md) 配置 .NET 10 API、Azure SQL、客户身份租户和核对后的账户绑定；[服务端说明](server/README.md) 包含运行与测试命令。未配置时显示设置未完成，浏览器不提供生产登录。代码、配置模板和自动检查不代表 Azure 已运行或两部 iPhone 已验证。范围以 [试点契约](docs/FAMILY-PILOT-CONTRACT.md) 为准；[完整家庭共享技术计划](docs/FAMILY-SHARING-TECH-PLAN.md) 中的其余内容仍是路线图。

基础设施可按 [Bicep 部署指南](docs/AZURE-BICEP-DEPLOYMENT.md) 创建：复用现有 Linux B1 计划，单独建立 Web App、托管身份及仅免费额度的 Azure SQL，不使用 Key Vault。脚本默认只做本机验证，部署须先预览并明确确认；身份注册、数据库初始化和 API 发布另行完成。免费 SQL 耗尽即暂停，不自动转付费；现有清理任务的数据库轮询仍需调整及真实环境验证。

首次邀请现可查看宝宝资料及喂养、尿布、睡眠、成长、里程碑和日常照护记录数量，填写最多三个邮箱并确认。正常原生试点登录后只能保存为账户隔离的**本机准备内容，尚未发送**；不创建家庭、不上传历史，原有记录不变。进行中的计时须先结束，确认前资料变化须重新查看。完整历史 API 和主应用共享数据接入尚未实现，详见 [手机端与 Azure 交接说明](docs/FAMILY-OWNER-ONBOARDING.md)。

无需 Azure 或登录即可使用专用的 [iPhone 界面预览](docs/FAMILY-UI-PREVIEW.md)：九种样例场景复用实际家庭界面，默认从「首次邀请」查看完整虚构历史的创建流程。所有操作只在内存中模拟，退出即重置。`ui-preview` 构建使用独立更新频道，不会绕过真实登录。

## Windows 上启动

1. 安装 Node.js LTS（建议 Node 24 LTS）、Git、VS Code。
2. 在 PowerShell 中克隆仓库并进入项目目录（如果已下载源码，直接在包含 `package.json` 的文件夹打开 PowerShell）：

```powershell
git clone https://github.com/github4me/my-little-days.git
cd my-little-days
npm ci
npm start
```

3. 预览原有本机功能时，可使用与项目 SDK 57 兼容的 Expo Go。电脑和手机连接同一个 Wi-Fi，在手机相机扫描终端二维码。首次安装依赖和加载开发包需要联网；家庭试点登录必须使用新的签名原生构建，不能用 Expo Go 验收。
4. 第一次打开：进入「我的」，填写宝宝名字、出生日期（YYYY-MM-DD）和性别。
5. 如 Windows 防火墙提示，请仅允许开发网络所需的专用网络访问。局域网无法连接时，可在可信网络使用 Expo 的 tunnel 模式；这会通过中转传送开发包。原有本机照护记录不上传；配置后的独立家庭试点会发送明确创建的测试家庭、邀请操作及已保存的测试瓶喂。

如果 App Store 的 Expo Go 版本不兼容 SDK 57，不要随意升级/降级单个包。使用下面的 EAS 内部分发构建，或整体对齐 Expo SDK 与 Expo Go。

### 先在 PC 查看界面

```powershell
npm run web
```

浏览器预览只供开发测试：原有本机数据保存在该浏览器的 localStorage，与 iPhone 数据独立；清除浏览器数据会丢失预览记录。网页不支持本地手机通知，家庭试点页只提供说明，不开放生产账户登录。手机安装版使用 SQLite，试点使用独立的数据库和账户/家庭空间。

### 安装为独立 iPhone App

Expo Go 是开发工具。日常使用、关掉电脑后独立启动、通知及家庭试点登录验收，应使用签名的独立安装包。

当前源码版本为 **0.2.0**。新增的登录、浏览器认证、SecureStore 依赖及 `mylittledays` 链接协议要求安装新原生构建；版本变化同时隔离 `appVersion` 更新运行时，不能把试点 JavaScript 更新发给旧 0.1.1 安装包。本次未生成新的 IPA、TestFlight 构建或发布 OTA 更新。配置试点公共环境变量后，再按设置指南构建并在两部测试手机上验收。

准备 Expo 账号和适用的 Apple Developer 账号后：

```powershell
npx eas-cli login
npx eas-cli build:configure
npx eas-cli device:create
npx eas-cli build --platform ios --profile preview
```

按向导配置团队、签名与设备，使用 EAS 返回的安装链接安装。已有安装或数据后，不要随意更改 `app.json` 中的应用身份。项目包含 `preview` 内部分发及 `production` 正式构建配置；向 TestFlight 上传构建与提交 App Store 审核是不同步骤。

参考：[Expo 云端开发构建](https://docs.expo.dev/develop/development-builds/introduction/)、[内部测试分发](https://docs.expo.dev/build/internal-distribution/)。

## 使用说明

- 首页「睡了」立即保存入睡时间；「醒了」结束当前睡眠。补录用卡片下方入口。
- 喂奶快捷数量只是输入选项，不是喂养建议。亲喂时长不转换成毫升。
- 「记录」可切换日历与柱状图。日历按日或周浏览全部或单类记录；柱状图按所选范围汇总并倒序展示历史。新增记录从首页进入。
- 「成长」保留实测曲线和测量记录；测量从此页添加。标准曲线只覆盖 0–24 月，不向外推算。里程碑入口已移除，旧备份中的里程碑数据仍保留，不自动删除。
- 提醒在「我的」设置。喂养可选「随最新喂养」：每次保存、编辑、删除或恢复记录后，应用以开始时间最新的一次喂养加上设定间隔重新安排提醒；也可选仅提醒一次或每天固定时间。上次成功添加的提醒设定会在下次进入时恢复。免打扰/专注模式和系统通知权限可能影响呈现。没有自动作息建议。
- 「导出备份文件」后在 iPhone 分享菜单选择「存储到文件」，自行选择位置。应用不会自动上传备份；选择 iCloud 等位置时，由用户选择的系统服务处理。
- 导入前会预览姓名与记录数量，确认后整体替换，不合并。恢复不改变当前已安排的提醒。
- 备份为未加密 JSON，包含原有本机宝宝档案、喂养/睡眠/尿布/成长等记录及日常照护记录，不含本机头像、语言与主题偏好、提醒设定、系统通知计划、早教选择与打卡或独立家庭试点数据与凭据。换机、卸载前保存本机备份。

## 时间与数据边界

事件用带时区的 ISO 时间保存。显示、日期筛选和每日汇总使用当前设备时区（墨尔本设备会采用当地夏令时），旅行改变设备时区会重新分配日统计。生日是无时区的日历日期。手动编辑精度为分钟，首页即时计时保存到毫秒。

睡眠按实际时间差计算，统计合并重叠睡眠区间；进行中睡眠只统计至当前时刻。没有记录的天不等同于实际没有进食或睡眠。

WHO 参考来源、原始表格校验和与绘图口径详见 `docs/WHO-SOURCES.md`。曲线只用于趋势展示，不做诊断、精确百分位计算或早产矫正月龄判断。

原有手机记录存在应用沙盒 SQLite，无需账号，也不会因登录家庭试点而上传或自动同步。试点另存经服务器核对的账户/家庭缓存、私人草稿和队列；配置服务后，只有试点的明确创建、邀请、保存等操作发送到该服务。试点不会共享本机计时器、通知、图表或历史备份。

应用通过 Expo 更新服务检查和下载软件更新，可能交换技术元数据，但更新请求不包含宝宝记录或照片。系统级设备备份遵循手机系统设置，不等于应用自动同步记录。早教内容供家长参考，不是宝宝的屏幕课程或发育评估。

## 验证

```powershell
npm run verify
npm run export:ios
npm run export:web
```

- `verify`：TypeScript、数据/统计/WHO 与家庭试点单元测试、真实试点控制器的确定性测试桩（`test:family-controller`）及中英文界面权限/确认流程（`test:family-ui`）。测试模拟身份、HTTP、SQLite 和原生控件边界，不代替 iPhone 验收。
- `export:ios`：生成 iOS JavaScript/Hermes 资源包；不是 IPA 编译、签名或真机验证。
- 浏览器回归和后端测试见 [验证说明](docs/VALIDATION.md)。`.NET 10` 后端运行 `dotnet test server/LittleDays.FamilyApi.Tests`；只有设置指向可丢弃 SQL Server `master` 的 `FAMILY_TEST_SQL_CONNECTION` 才执行真实 SQL 测试，不能指向试点或生产数据库。详见 [服务端说明](server/README.md)。

## 项目结构

- `App.tsx`：简洁首页、成长和页面切换。
- `src/Records.tsx`：三个分类、趋势图、每日汇总和明细。
- `src/EntryEditor.tsx`：五类记录表单与原生时间选择器。
- `src/Settings.tsx`：档案、通知、备份恢复。
- `src/PlayLearning.tsx`、`src/learning.ts`：早教活动、月龄选择与打卡。
- `src/DailyCare.tsx`、`src/care.ts`：日常照护历史与体温输入验证。
- `src/recordRange.ts`：记录时间范围与图表分组。
- `src/PrivacySupport.tsx`：隐私说明与支持信息。
- `src/domain.ts`：版本化数据模型、校验与统计。
- `src/storage.ts`：SQLite 事务保存与恢复副本；`.web.ts` 是开发预览实现。
- `src/backup.ts`：手机文件选择与导出。
- `src/reminders.ts`：设备本地通知，不获取推送 token。
- `src/growth.ts`、`assets/who/`：本地 WHO 参考数据。
- `src/family/`：独立试点界面、身份认证、网络契约、缓存、草稿和持久队列。
- `server/LittleDays.FamilyApi/`、`server/LittleDays.FamilyApi.Tests/`：.NET 10 API、EF SQL 迁移与后端测试。
- `infra/`、`.github/workflows/`：设置模板、SQL 权限脚本、CI 和受保护环境下的手动试点部署；不会因合并代码自动部署。
